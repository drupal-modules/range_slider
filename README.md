INTRODUCTION
------------

Provides integration with https://andreruffert.github.io/range-slider-element

This module provides a modern, accessible range slider form element for Drupal using the range-slider-element web component.


INSTALLATION
------------

Install as usual, see [Installing contributed modules](https://drupal.org/node/895232) for further information.
